# Лидеры Права — платформа конкурса

Репозиторий сайта `lideryprava.ru`. Ветка `feature/lidery-prava-platform` — рабочая ветка перехода на новую платформу конкурса.

## Что в этой ветке

| Путь | Содержимое | Состояние |
|---|---|---|
| `docs/tz/` | Техническое задание на новую платформу (14 разделов) | Готово к согласованию |
| `platform/` | Новая платформа: сервер, миграции БД, админка | Каркас, ведётся разработка |
| `ops/` | nginx, systemd, бэкапы, выкат | Черновики конфигураций |
| корень репозитория | Текущий работающий сайт (`index.html`, `assets/`, `server.py`, `admin.html`, …) | **Не изменяется**, точка отката |

Точка входа в документацию — [`docs/tz/00-index.md`](docs/tz/00-index.md).

## Порядок работ

1. **Согласовать ТЗ** (`docs/tz/`), закрыть вопросы из [`13-questions.md`](docs/tz/13-questions.md).
2. **Устранить инцидент безопасности** на действующем сайте — публичный доступ к `/data/applications.db`, `/data/auth.log`, `/server.py` (см. [`11-security.md`](docs/tz/11-security.md) и `ops/nginx/`). Работы по переносу данных не начинаются до закрытия доступа.
3. **Собрать ядро** в `platform/`, проверить гейты разделения (`platform/scripts/check-decoupling.sh`).
4. **Дизайн и прототипы** — отдельный этап, затем вёрстка публичной части.
5. **Тестовый стенд**, приёмка по сценариям [`12-acceptance.md`](docs/tz/12-acceptance.md).
6. **Выкат** и перенос данных по [`10-migration.md`](docs/tz/10-migration.md).

## Правила работы с этим репозиторием

1. Ветка `main` — текущий работающий сайт. Прямые изменения в `main` без проверенной ветки запрещены.
2. Секреты, пароли и файлы окружения в репозиторий не попадают. Имя администратора и пароль задаются только через переменные окружения; значение по умолчанию из старой документации (`change-me-please`) использовать запрещено.
3. История git не переписывается, force push запрещён.
4. Доменный код проекта «ТехнологИИ Права» в этот репозиторий не переносится: только очищенное ядро, проверяемое гейтами ([`03-architecture.md`](docs/tz/03-architecture.md), п. 6).

## Текущий сайт (не изменяется в этой ветке)

Сайт работает как статика плюс небольшой сервер приёма заявок:

- публичная форма отправляет заявку на сервер;
- данные сохраняются в SQLite `data/applications.db`;
- админ-панель — по адресу `/admin`;
- в админке: список заявок, поиск, статусы, заметки.

Запуск для локальной проверки:

```bash
ADMIN_LOGIN="admin" ADMIN_PASSWORD="<задайте-свой-пароль>" python3 server.py
```

Адрес по умолчанию: `http://127.0.0.1:8000/` (сайт), `http://127.0.0.1:8000/admin` (админка).

Каталог `data/` с базой и журналами **не должен быть доступен по HTTP** — см. `ops/nginx/`.
