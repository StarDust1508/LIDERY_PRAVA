# Лист изменений: Положение «Лидеры права – 2027» и Приложения № 1–14

**Редакция:** от 4 октября 2026 года.
**Основание:** решение учредителя (Ассоциация выпускников СЮИ – СГАП – СГЮА) и Оргкомитета конкурса; правки согласованы владельцем проекта.
**Что сделано:** изменения внесены непосредственно в документы. Обновлённые файлы — `docs/source/Положение_Лидеры_права_2027.docx` и `docs/source/Приложения_Лидеры_права_2027.docx`; PDF для публикации — `platform/public/docs/`.
**Что требуется:** утверждение Председателем Правления Ассоциации и публикация на официальных ресурсах (п. 1.9 Положения). До публикации изменённые PDF считаются проектом.

## 1. Изменения в Положении

### 1.1. Пункт 17.3 — электронная форма подачи заявки

| | Текст |
|---|---|
| Было | «Электронная форма подачи заявки: `https://forms.yandex.ru/cloud/68f727b949af4705e4c92a3d/`.» |
| Стало | «Электронная форма подачи заявки: `https://lideryprava.ru/apply`.» |

**Причина:** заявки принимаются только на сайте; внешние формы не используются. Раздел `/apply` — единственный канал подачи.

### 1.2. Пункт 7.2 — форма представления согласий

| | Текст |
|---|---|
| Было | «…согласия на обработку персональных данных каждого участника и наставника (Приложения № 10–12), а для участников, не достигших 18 лет, — согласие законного представителя (Приложение № 11).» |
| Стало | «…согласия на обработку персональных данных каждого участника и наставника (Приложения № 10–12), **оформляемые в электронной форме при заполнении заявки**, а для участников, не достигших 18 лет, — согласие законного представителя (Приложение № 11).» |

**Причина:** максимальное удобство участника. Согласие даётся электронно; представление подписанных экземпляров не требуется.

### 1.3. Пункты 7.2 и 14.3 — электронная форма согласия

В пункт 7.2 добавлено уточнение для несовершеннолетних:

> «…а для участников, не достигших 18 лет, — согласие законного представителя (Приложение № 11) **с приложением скана подписанного бланка**.»

В пункт 14.3 добавлены предложения:

> «Согласия могут быть оформлены в электронной форме посредством проставления отметки на официальном сайте Конкурса; при этом фиксируются дата, время, сетевой адрес и версия текста согласия. **Согласие законного представителя (Приложение № 11) дополнительно представляется в виде скана подписанного бланка.**»

**Причина:** согласие за несовершеннолетнего даёт законный представитель, который не является пользователем сайта. Электронной отметки недостаточно — нужен подписанный документ.

**Причина:** юридическое основание для электронной формы согласия; требование Федерального закона № 152-ФЗ (согласие должно быть конкретным, предметным, информированным, сознательным и однозначным — отметка на сайте с фиксацией версии текста этому соответствует).

### 1.4. Пункт 9.3.1 — состав групп финального этапа

| | Текст |
|---|---|
| Было | «Команды-финалисты формируются Оргкомитетом в 4 (четыре) группы по 3 (три) команды с учетом выбранных направлений (Приложение № 2).» |
| Стало | «Команды-финалисты формируются Оргкомитетом **в группы по 3 (три) команды; при числе финалистов, не кратном трём, состав групп определяется Оргкомитетом** с учетом выбранных направлений (Приложение № 2).» |

**Причина:** устранение противоречия. Пункт 8.6 говорит «команды (от 10)», календарный план называл 12. При 10 финалистах группы формируются как 3 + 3 + 2 + 2, из каждой группы в дебаты проходят две команды (8 команд, 4 пары), победители пар образуют Гранд-финал из 4 команд — структура п. 9.4–9.5 сохраняется.

### 1.5. Календарный план (п. 6.3) — число финалистов

| | Текст |
|---|---|
| Было | «Опубликование протокола итогов первого этапа **(12 команд-финалистов)**» |
| Стало | «Опубликование протокола итогов первого этапа **(от 10 команд-финалистов)**» |

**Причина:** приведение календарного плана в соответствие с п. 8.6.

### 1.6. Шапка документа — исключён блок согласования с СГЮА

| | Содержимое шапки |
|---|---|
| Было | Две колонки: «СОГЛАСОВАНО. Ректор ФГБОУ ВО „Саратовская государственная юридическая академия“» и «УТВЕРЖДАЮ. Председатель Правления Ассоциации» |
| Стало | Одна колонка: «УТВЕРЖДАЮ. Председатель Правления Ассоциации» |

**Причина:** решение учредителя — СГЮА как самостоятельная сторона из документов конкурса исключается. Пункт 1.9 Положения предусматривает утверждение Положения Председателем Правления Ассоциации; согласование с иной организацией не требуется.

**Важно:** слова «Саратовской государственной юридической академии» остаются в полном наименовании учредителя — это часть наименования организации по ЕГРЮЛ (ОГРН 1087799025522) и изменению не подлежит.

## 4. Что нужно сделать после изменений

1. Утвердить изменённую редакцию Положения и Приложений Председателем Правления Ассоциации (п. 1.9).
2. Опубликовать подписанные PDF на официальных ресурсах — с этого момента редакция вступает в силу.
3. Передать в работу подписанные сканы: они заменят проектные PDF в `platform/public/docs/`.
4. Зафиксировать в системе версию документов: `2026-10-04` — чтобы при подаче заявки было доказательство, с какой редакцией согласился участник.
