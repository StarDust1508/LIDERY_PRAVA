## 5. Открытые технические решения

| № | Решение | Варианты | Что мешает решить |
|---|---|---|---|
| Т1 | Интеграция с Яндекс.Формой | (а) ручной импорт выгрузки, (б) автоматический по API, (в) отказ в пользу формы сайта | Нужен ответ Л4 и О8 |
| Т2 | Почтовый провайдер | UniSender / SMTP Ассоциации / иной | Нужен ответ В4 |
| Т3 | Хранение видео мастер-классов | ссылка на ВК / загрузка файла / оба | Нужен ответ Оргкомитета о площадке вебинаров |
| Т4 | Судьба старых заявок SQLite | отдельная таблица истории / миграция в новую модель | Модели разные; по умолчанию — история (раздел 10) |
| Т5 | Тестовый стенд | поддомен / закрытый каталог | Нужен ответ Л12 |
| Т6 | Генерация сертификатов участников | делать / не делать | Нужен ответ О10 |
