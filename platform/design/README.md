# Дизайн функциональных экранов платформы

Прототип и дизайн-система **функциональных** экранов конкурса «Лидеры права – 2027»:
мастер подачи заявки, личный кабинет команды и админ-панель.

Маркетинговые страницы (главная, «О конкурсе», этапы, мастер-классы, архив
законопроектов, победители, документы) здесь **не прототипируются**: их структура
определяется финальным дизайном и делается отдельным этапом (ТЗ 08, п. 9.1–9.2).

## Что внутри

| Файл | Что это |
|---|---|
| `DESIGN.md` | Дизайн-система: токены (цвет, типографика, отступы, радиусы, состояния), проверка контраста, правила компонентов |
| `prototype/index.html` | Обзор прототипа: список экранов и переключатель «десктоп / мобильный» |
| `prototype/apply.html` | Мастер подачи заявки: 6 шагов, автосохранение черновика, ошибки рядом с полями, состояния материала, режим «приём заявок закрыт» |
| `prototype/cabinet-access.html` | Вход в личный кабинет: номер заявки, почта капитана, состояние ошибки |
| `prototype/cabinet.html` | Сводка: номер, статус заявки, что осталось догрузить, ближайший срок |
| `prototype/cabinet-team.html` | Состав команды и наставники, правило изменения состава |
| `prototype/cabinet-materials.html` | Комплект материалов: тип, файл или ссылка, статус, замечание, срок досдачи |
| `prototype/cabinet-deadlines.html` | Сроки этапов по МСК и режим «срок пропущен» с контактами Оргкомитета |
| `prototype/admin-applications.html` | Список заявок: поиск, фильтры, выгрузка |
| `prototype/admin-application.html` | Карточка заявки: участники, материалы, техническая проверка, замечания |
| `prototype/admin-evaluation.html` | Оценочный лист: балл и обоснование по критериям, итог, рекомендации, публикация протокола |
| `prototype/assets/` | Токены, стили, локальные шрифты, скрипт прототипа |

Открыть прототип: `prototype/index.html` в браузере (сервер не нужен).

## Как получен

Прототип изготовлен в **OpenDesign** — проектная среда для дизайна, как требует
ТЗ 08, п. 9.3 и рабочие правила проекта. Задание: функциональные экраны в текущем
визуальном языке сайта (палитра `#F5F1E9` / `#ECE6DA` / `#2C2722` / `#E5231C`,
Inter и JetBrains Mono), новый бренд не изобретается до передачи Оргкомитетом
логотипа и фирменного стиля.

**Шрифты подключены локально.** В исходном артефакте был импорт Google Fonts;
он заменён на самодостаточные `@font-face` с файлами из репозитория сайта
(`assets/fonts`), потому что конкурс обрабатывает персональные данные граждан
Российской Федерации и не обращается к зарубежным сервисам (п. 14.4 Положения).
Внешних ресурсов в прототипе не осталось — только ссылки на сообщество
«ВКонтакте» и страницу руководителя Оргкомитета, это контакты, а не зависимости.

## Что проверено

- линтер артефактов OpenDesign: 0 замечаний P0/P1 по всем десяти экранам;
- целостность разметки: один `<h1>` на страницу, `lang="ru"`, у каждого поля
  есть связанная подпись `<label for=…>`;
- 102 локальные ссылки разрешаются, битых нет;
- контраст по WCAG 2.1 AA посчитан и зафиксирован в `DESIGN.md`, раздел 5;
  красный `#E5231C` (4,06:1) не используется для обычного текста — только для
  крупного, графики и заливок;
- мобильный вид — в самих страницах: таблицы ниже 900 px становятся карточками,
  горизонтальной прокрутки нет.

## Ограничения прототипа

Данные демонстрационные (номера заявок, команды, участники, баллы вымышлены;
контакты Оргкомитета подлинные). Серверной части нет: вход, отправка заявки,
загрузка файлов и выгрузка CSV имитируются в браузере. Эмблема — плейсхолдер в
духе текущей. Панель состояний внизу экрана — инструмент прототипа, в продукт
она не переносится.

## Как это связано с кодом

Вёрстка ведётся по этому прототипу: `platform/web` (публичная часть, мастер и
кабинет) и `platform/admin` (админка), общий код — в `platform/shared`.
При смене оформления меняются значения токенов, а не структура кода (ТЗ 03,
«Что делается в каком порядке»).
