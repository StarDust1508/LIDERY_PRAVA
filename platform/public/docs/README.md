# Документы для публикации на сайте

Каталог содержит файлы, доступные посетителям сайта.

## Положение о конкурсе

| Файл | Что это |
|---|---|
| `polozhenie-lidery-prava-2027.pdf` | Положение о проведении Десятого ежегодного федерального научно-образовательного конкурса «Лидеры права – 2027», 23 страницы |
| `prilozheniya-lidery-prava-2027.pdf` | Приложения № 1–14 к Положению (форма заявки, направления, требования к законопроекту, пояснительной записке, перечню актов, оформлению, видеоролику, регламент дебатов, оценочный лист, согласия № 10–13, форма апелляции), 26 страниц |
| `../../docs/source/Положение_Лидеры_права_2027.docx` | Исходный документ Положения |
| `../../docs/source/Приложения_Лидеры_права_2027.docx` | Исходный документ Приложений |

**Важно:** PDF изготовлен конвертацией исходного документа Word с **внесёнными правками** редакции от 4 октября 2026 года (список — `../../docs/source/ЛИСТ_ИЗМЕНЕНИЙ_к_Положению_2027.md`). Подписей и печатей в нём нет: в исходнике стоят незаполненные места для подписи Председателя Правления Ассоциации.

Для публикации на сайте требуется **подписанный и заверенный** экземпляр:

1. Оргкомитет подписывает и утверждает Положение **и Приложения** (п. 1.9: утверждается Председателем Правления Ассоциации, вступает в силу с момента опубликования на официальных ресурсах).
2. Скан подписанного документа (PDF) помещается в этот каталог под именем `polozhenie-lidery-prava-2027-signed.pdf`.
3. Страница `/about/regulations` публикует **обе** версии: подписанный скан как официальный документ и текстовый PDF для чтения и поиска.

## Формы Приложений № 1–14

Формы получены и опубликованы единым PDF `prilozheniya-lidery-prava-2027.pdf`. При публикации на сайте раздел «Документы» дополнительно отдаёт каждое приложение отдельной страницей `/legal/appendix/:number`; при необходимости единый PDF разбивается на файлы `appendix-01.pdf` … `appendix-14.pdf`.

**Что определяют формы:**
- Приложение № 1 — обязательный состав полей заявки;
- Приложение № 2 — 7 направлений конкурса (совпадают с сидом `directions`);
- Приложения № 3–8 — требования к материалам и регламент дебатов (публикуются и используются как памятки);
- Приложение № 9 — форма оценочного листа (балл + обоснование по критерию, итог, рекомендации);
- Приложения № 10–13 — согласия: сайт генерирует заполненные бланки, команда подписывает и загружает сканы;
- Приложение № 14 — форма апелляционного заявления.

## Требования к публикуемым документам

1. Имя файла — латиницей, без пробелов: `polozhenie-lidery-prava-2027.pdf`, `oferta.pdf`, `pdn-consent.pdf`.
2. Каждый документ имеет версию и дату редакции, которые отображаются на странице.
3. Скачиваемая версия совпадает по тексту со страницей сайта.
4. Юридические документы публикуются от имени Ассоциации выпускников (см. `docs/tz/09-legal.md`).
