# Документы конкурса «Лидеры права – 2027»

Каталог статических PDF, которые отдаются сайтом по адресам `/docs/...`.

| Файл | Что это | Страниц |
|---|---|---|
| `polozhenie-lidery-prava-2027.pdf` | Положение о Десятом конкурсе (редакция 21.10.2026) | 26 |

Изменение против предыдущей версии: в Приложении № 8 (регламент дебатов)
удалены раунды 6–7, из-за чего приложение занимает одну страницу, а общий
файл — 28 страниц.

Пересборка: DOCX → PDF через LibreOffice, затем
`python3 platform/scripts/split-appendices.py <общий PDF>` нарезает приложения.
