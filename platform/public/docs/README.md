# Документы для публикации на сайте

Каталог содержит файлы, доступные посетителям сайта.

## Положение о конкурсе

| Файл | Что это |
|---|---|
| `polozhenie-lidery-prava-2027.pdf` | Положение о проведении Десятого ежегодного федерального научно-образовательного конкурса «Лидеры права – 2027», 23 страницы |
| `../../docs/source/Положение_Лидеры_права_2027.docx` | Исходный документ, из которого изготовлен PDF |

**Важно:** данный PDF изготовлен автоматической конвертацией исходного документа Word. В нём нет подписей и печатей: в исходнике стоят незаполненные места для подписи («\_\_\_\_» и «\_\_» \_\_\_\_ 2026 г.) руководителя Академии и Председателя Правления Ассоциации.

Для публикации на сайте требуется **подписанный и заверенный** экземпляр:

1. Оргкомитет подписывает и утверждает Положение (п. 1.9: утверждается Председателем Правления Ассоциации, вступает в силу с момента опубликования на официальных ресурсах).
2. Скан подписанного документа (PDF) помещается в этот каталог под именем `polozhenie-lidery-prava-2027-signed.pdf`.
3. Страница `/about/regulations` публикует **обе** версии: подписанный скан как официальный документ и текстовый PDF для чтения и поиска.

## Формы Приложений № 1–14

Формы к Положению (заявка, требования к законопроекту, согласия, оценочный лист, форма апелляции и другие) в полученном документе **отсутствуют** — есть только ссылки. До их получения раздел «Документы» публикует одно Положение. Формы добавляются по мере передачи Оргкомитетом и размещаются как `appendix-01.pdf` … `appendix-14.pdf`.

## Требования к публикуемым документам

1. Имя файла — латиницей, без пробелов: `polozhenie-lidery-prava-2027.pdf`, `oferta.pdf`, `pdn-consent.pdf`.
2. Каждый документ имеет версию и дату редакции, которые отображаются на странице.
3. Скачиваемая версия совпадает по тексту со страницей сайта.
4. Юридические документы публикуются от имени Ассоциации выпускников (см. `docs/tz/09-legal.md`).
